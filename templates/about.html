Tentang Proyek

Sistem Prediksi Diabetes Menggunakan Algoritma C4.5

Latar Belakang

Aplikasi DiabetesCheck dikembangkan untuk membantu deteksi dini risiko diabetes. Dengan teknik Data Mining, aplikasi ini menganalisis pola indikator kesehatan untuk memberikan prediksi risiko diabetes secara cepat berdasarkan 5 pertanyaan sederhana.

Algoritma C4.5

Sistem menggunakan algoritma C4.5 (Decision Tree) berbasis entropy / information gain, diimplementasikan dengan DecisionTreeClassifier(criterion='entropy') dari Scikit-Learn. Kedalaman pohon (max_depth) ditentukan melalui 5-Fold Cross Validation agar model tidak overfitting. Pohon keputusan yang dihasilkan transparan, sehingga dasar pengambilan keputusan sistem mudah ditelusuri.

Dataset & Preprocessing

Model dilatih pada dataset BRFSS 2015 (diabetes_012_health_indicators_BRFSS2015.csv) berisi 253.680 responden. Setelah data duplikat dihapus, label 3 kelas (Tidak Diabetes / Prediabetes / Diabetes) digabung menjadi klasifikasi biner (Tidak Diabetes vs Diabetes). Karena data tidak seimbang (rasio ±4,8 : 1), kelas mayoritas pada data training diseimbangkan dengan undersampling — data testing tetap dibiarkan asli agar evaluasi mencerminkan kondisi nyata.

Performa Model

Diuji pada data testing yang tidak diseimbangkan, model memperoleh Accuracy 68,12%, Balanced Accuracy 72,13%, dan ROC-AUC 0,798. Balanced Accuracy dan ROC-AUC digunakan sebagai patokan utama karena lebih adil untuk data yang tidak seimbang dibanding accuracy biasa.

Parameter Analisis (5 Fitur Utama)
  • Tekanan Darah Tinggi (HighBP)
  • Kolesterol Tinggi (HighChol)
  • BMI — dihitung otomatis dari Tinggi & Berat Badan
  • Kondisi Kesehatan Umum (GenHlth)
  • Kelompok Usia (Age)

Dipilih dari 21 fitur pada dataset asli berdasarkan feature importance hasil model C4.5 — 5 fitur ini dipakai langsung pada form prediksi di aplikasi.
